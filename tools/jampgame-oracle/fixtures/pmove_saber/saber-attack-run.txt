# commands to build the run gait, then keep running forward while holding
# BUTTON_ATTACK (1) for 12. Exercises a DIFFERENT arc than the standing swing:
# with forwardmove>0 the attack path (bg_saber.c:3698) calls

# (velocity[2]<=100, NULL saber, zero force power) skips the flip/special branch
# and falls to PM_CheckStabDown (one extra forward pm->trace against the world,
# returns LS_NONE) -> LS_A_T2B, the forward overhead slash. Distinct saberMove /
# torso anim / weaponTime progression vs scenario 3, and ntr rises by the extra
# stab-down probe on the swing step. rng holds 89abcdef.
# origin z 24.25 = 0x41c20000.
